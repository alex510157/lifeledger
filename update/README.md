# LifeLedger 自動更新包

家人電腦上的 LifeLedger（分享版）每天更新完月報後，會讀這裡的 `version.json`，
有新版就下載 zip、核對大小和 SHA-256，再更新 `_自動化工具` 底下的程式和說明
（不碰 `設定`、`紀錄`，舊檔備份在 `_更新備份`）。

- 這個資料夾由電腦端 `make_share.py` 產生（`LifeLedger_分享版\update\`），不要手動修改。
- 每次發新版：用新的 `update\` 換掉這裡的檔案、開 PR；**合併之後**家人電腦才會收到。
- zip 裡只有分享版的程式（已經過 `make_share.py` 的個人資料檢查），沒有密碼、帳單或設定。
